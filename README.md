# IP期限管理システム

特許・商標・意匠の期限を一元管理する Web アプリケーションです。

## 技術スタック

- Python 3.11+
- SQLite（`deadline.db` をローカルに自動生成）
- Streamlit（Web UI）
- pandas（一覧表示・CSV出力）

## セットアップ・起動

```bash
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動的に開きます。

## 機能

| ページ | 内容 |
|--------|------|
| ダッシュボード | 期限超過・30日/60日以内の期限をカード表示。案件ステータス別サマリー |
| 案件一覧 | 全案件を種別・ステータス・クライアントでフィルタして表示。CSVダウンロード対応 |
| 案件登録 | 新規登録・編集・削除。登録時に期限を自動計算 |
| 期限管理 | 案件ごとの期限一覧。完了チェック・手動追加・削除 |

## 期限自動計算ルール

### 特許
- 審査請求期限：出願日 + 3年（特許法48条の3）
- 年金（第1〜3年）：登録日 + 1年（まとめ納付表示）
- 年金（第4〜20年）：登録日 + N年を年次ごとに生成

### 商標
- 更新期限（10年）：登録日 + 10年
- 更新期限（20年）：登録日 + 20年

### 意匠
- 存続期間満了：登録日 + 25年
